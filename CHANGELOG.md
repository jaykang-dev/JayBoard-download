# Changelog

## 1.1.0 — 2026-11-05

- **Arrange your widgets:** move, resize and hide widgets on the dashboard. Widgets in the way slide aside
  or shrink so everything stays on your screen. Start from the right-click menu, ⌥⌘E / Ctrl+Alt+E or the app menu.
- **Edit in place:** click a to-do, goal or note to edit it (Enter saves, Esc cancels).
- **Add events from the calendar:** the **+** on each day, double-click a day, or **+ Add event**.
- Right-click menu on the dashboard: edit widgets, show hidden widgets, reset layout, My Schedule, Settings.
- Fixed double-clicking a day in My Schedule.

## 1.0.2 — 2026-11-03

- **Windows:** *Display* now lists your monitors by their real names (for example "Odyssey G5") instead of "Display 1".
- **Windows:** your chosen monitor is remembered even after reconnecting it, restarting or using a dock.
- **Windows:** the dashboard keeps filling the screen on monitors with different scaling (for example a 150% laptop and a 100% monitor).

## 1.0.1 — 2026-11-03

- **Windows:** fixed the dashboard not showing on the desktop (it was hidden behind the desktop window).
- **Windows:** added *Help › Open Troubleshooting Log* to help diagnose problems.

## 1.0.0 — 2026-11-03

First release.

- Desktop dashboard: today's to-dos, unfinished to-dos, progress dashboard, weekly to-dos,
  monthly goals, goals N months ahead, "On my mind" notes, and a month calendar
- My Schedule window: month view with events and to-dos, and a dashboard for any day
- Google Calendar via iCal address (read-only), plus your own events you can add, edit and delete
- Settings: language (Korean / English), panel opacity, display selection, click-through, start at login,
  data export / import
- macOS (Apple Silicon and Intel) and Windows 10/11 (64-bit)
